# 基于小米AIoT平台的实训项目
## 项目简介
小米AIoT开发平台是一种创新的嵌入式智能开发平台，采用模块化设计，实现高效、灵活的定制化智能硬件系统搭建。该平台由母板和子板组成，其中母板负责供电、连接和通信等基础功能，而子板则搭载不同元器件和芯片模组，构建具体产品功能。母板作为子板的基座，子板通过磁吸方式与母板连接。用户可以根据需求，通过不同的子板组合实现模块化设计，从而进行灵活的定制和扩展。 
本小组通过学习嵌入式、单片机以及通信原理的基本知识，在熟悉Xiaomi AIoT开发平台（又称Xiaomi AIoT实训箱）的原理和操作后，对U1、U2计算子板，7种传感器子板，4种执行器子板的芯片，驱动原理和通信原理进行了深入的探讨和研究，实现了全部7项基础任务模块，并成功完成了其功能测试。
在此基础上，本小组设计并实现了具有一定实用性的创新场景——智能教室控制中枢。智能教室是由1个主控制菜单模式和9个子模式实现的。主菜单模式通过按键1-9实现不同子模式的切换。进入对应的子模式后进行不同的逻辑不同的控制操作，并可退出到主控制菜单模式，再控制进入其它模式，控制其它设备。 
最终，本小组实现了一个能够手动按键、自动和NFC控制设备，和一键关闭所有设备的智能教室控制中枢，可在此基础上扩展出更多模式，以操作控制更多的智能设备。
